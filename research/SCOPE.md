# Project Scope

## The project IS

A controlled research study investigating whether AI assistance
changes the relationship between immediate independent
performance and later retention/transfer.

The application is the research instrument.

## The project is NOT

- A general AI tutor
- A ChatGPT clone
- A RAG application
- A general educational platform
- A school management system
- A personalized AI teacher
- A gamification platform
- An adaptive learning platform

## Version 1 must NOT contain

- RAG
- LangChain
- LangGraph
- RL
- complex learner models
- recommendation systems
- social features
- gamification
- unnecessary dashboards

## Future features

Only considered if research results justify them.
