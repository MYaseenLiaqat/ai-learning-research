# Pilot Protocol Clarification v0.3

## Target participant

This pilot is intended for early-stage programmers with basic Python prerequisites, such as students in an introductory programming sequence.

This is not intended for:

- complete programming novices
- highly proficient or professional Python programmers

## Intended learning construct

The narrow target is basic conditional iteration with a Python `for` loop:

INITIALIZE → ITERATE → CHECK → UPDATE → RESULT

Supported concepts include:

- variables
- assignment
- simple lists
- comparisons
- `if`
- indentation
- basic arithmetic

The pilot is not designed to teach or assess:

- while loops
- nested loops
- append/list construction as a required target skill
- dictionaries
- functions as new solution abstraction
- recursion
- advanced libraries

## Assessment sequence for the pilot

Day 0:

- learning material
- Supported task
- Immediate independent assessment

Day 7 ± 2 days:

- Delayed retention assessment

Day 14 ± 2 days:

- Transfer assessment

Day 21 ± 3 days:

- Criterion assessment

The actual research pilot intends to use the full schedule unless the research design is deliberately changed later.

## Manual reminder protocol

Manual reminders should be:

- standardized across both conditions
- sent at the same time relative to the scheduled assessment
- limited to scheduling information only
- free of instruction, loop syntax, hints, or code examples

Example pattern:

> This is a reminder to complete the next assessment. Please complete it as soon as possible.

No educational content should be included in the reminder.

## Scope for this pilot

This step focuses on content and instrument quality. It does not add reminder software, adaptive intervention, or recruitment infrastructure.
