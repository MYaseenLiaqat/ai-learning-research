# Loops Prerequisite Screener v0.3

## Purpose

This screener is not a target-concept pretest. It is a short eligibility check to confirm that a participant has the basic Python knowledge needed before the Loops module.

The small pilot will use this screener to calibrate floor/ceiling thresholds without teaching the target construct.

## Intended participant

Early-stage programmer with basic Python familiarity.

Not intended for:

- complete programming novices
- highly proficient or professional Python programmers

## Minimal screener (5 items + background)

### 1. Variable assignment

Which value is stored in `x` after this code runs?

```python
x = 7
x = x + 2
```

Target response: `9`

### 2. List reading

What is the value of `numbers[1]` in this list?

```python
numbers = [10, 20, 30]
```

Target response: `20`

### 3. Comparison

Which of the following expressions are `True`? Select all that apply.

```python
5 > 3
5 >= 5
5 < 3
5 <= 2
```

Target response: `5 > 3` and `5 >= 5` are true.

### 4. If statement

What is printed by this code?

```python
score = 75
if score >= 70:
    print("pass")
```

Target response: `pass`

### 5. Simple code reading / indentation

What is the final value of `score` in this code?

```python
score = 10
if score >= 10:
    score = score + 5
else:
    score = score - 5
```

Target response: `15`

## Background questions

These are informational only and should not be used to teach the target concept.

- How many introductory programming courses have you completed?
- How much Python experience do you have?
- Approximately how many hours of programming practice have you done?
- How familiar are you with basic Python syntax? (self-rating)

## Use in pilot

This screener should be used only to describe sample readiness and help identify severe floor effects. It should not be used to teach loops or to create a large target-concept pretest.

The final inclusion thresholds for a full study remain to be calibrated after the 3–5 person content pilot.
