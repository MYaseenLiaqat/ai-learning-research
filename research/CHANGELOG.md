# Research Instrument Changelog

## Protocol v0.4
Changed:
- AI treatment became a pedagogically constrained, learner-initiated tutor.
- Complete executable active-task solutions are prohibited.
- New learners freeze protocol v0.4; new controlled-AI learners freeze prompt 0.3.0.

Preserved:
- identical instruction across conditions;
- AI only during Supported;
- 20-minute Supported phase;
- 8 successful AI interactions;
- AI blocked in all independent assessments;
- no personalization, RAG, or adaptive intervention.

## Learning Module v0.4.0
Changed from v0.3.0:
- reorganized into three explicit lessons;
- stronger execution-model teaching and dry runs;
- clearer counting vs summation distinction;
- improved guided and mini-practice.

## Learning Module v0.3.0
Changed from v0.2.0:
- added INITIALIZE → ITERATE → CHECK → UPDATE → RESULT;
- added trace explanation, summation, comparison reminders, indentation guidance, common mistakes, guided practice, mini-practice.

## Task Instrument 0.3.1
Changed from 0.3.0:
- Criterion wording changed from ambiguous “overtime hours” to a defined “long shift” and total hours across qualifying shifts.
- Underlying grading behavior was preserved.

## Task Instrument 0.3.0
Changed from 0.2.0:
- removed participant-visible expected-result clueing;
- replaced filtered-list Transfer with transformed conditional accumulation;
- changed Criterion from transaction context to shift-hours context.

## Task Instrument 0.2.0
Changed from 0.1.0:
- made platform-provided inputs explicit;
- told participants not to redefine provided inputs;
- still displayed expected results;
- retained filtered-list Transfer and transaction Criterion.

## Task Instrument 0.1.0
- first seeded Loops pilot set;
- expected results were visible in prompts;
- Transfer used filtered-list construction;
- Criterion used transaction summation.

## AI Prompt 0.3.0
Changed from 0.2.0:
- complete active-task solution prohibited;
- learner initiation explicit;
- direct explanation, tracing, hints, and analogous examples allowed;
- adaptive/automatic intervention prohibited.

## AI Prompt 0.2.0
Changed from 0.1.0:
- added construct boundary and forbidden constructs;
- added research-hypothesis and cross-task-memory safeguards;
- added provided-input contract;
- still allowed complete solution if explicitly requested.

## AI Prompt 0.1.0
- initial fixed controlled-AI prompt;
- concise conceptual guidance/small hints;
- hidden-test, invented-task, and treatment-personalization safeguards.
